# 0014. One contract: every route declares its schemas, and the frontend's types are generated from them

- Status: Proposed
- Date: 20 Nov 2026
- Repos: backend and frontend
- PRD: API-01
- Regulation: Privacy Act 1988 (APP 11: send only what is needed)
- Sign-off: product owner

## Context

Two failure modes are common when an API's replies are whatever the handler returns. A whole database row goes out, so a column added later (a secret, a clinical field) reaches every screen that calls the route without anyone deciding it should. And the frontend copies the API's types by hand, so a backend change breaks screens at run time instead of at build time.

## Decision

- **Every route declares a request schema and a response schema** (Zod). Keys a response schema doesn't declare are left out of the reply, so a new column stays private until someone adds it on purpose. A guard test fails when a route has no response schema.
- **Handlers never return database rows directly**; they map rows to the declared reply.
- **A reply that doesn't match its schema** throws in tests. In staging and production it is never a 500 (the change may already be committed): the body is cut to the declared fields, and the route and the mismatched paths (never values) are logged and reported.
- **No credential-like key** (password, secret, token, hash) may appear in a reply; a test fails when one does.
- **The frontend's API types are generated** from the backend's OpenAPI document (`npm run contract` writes `src/lib/api/schema.d.ts` in the frontend), and CI fails when the generated file is out of date.

## Consequences

- Screens fail to build, not to run, when the API changes.
- Adding a field to a reply is a deliberate, reviewable change.

## Where it lives

- Backend: `contract/openapi.json`, generated by `npm run contract` and checked by `npm run check`; `src/lib/response-schema.ts`; `src/plugins/route-rules.ts`; `test/integration/routes.test.ts`. `/openapi.json` is served in development only, not in staging or production.
- Frontend: types generated from the backend's `contract/openapi.json` into `src/lib/api/schema.d.ts`.
